    ℹ️ What are the different backup views?
    📥 View Downloads — Manual backups you explicitly triggered
    🔄 View Backups — Periodic auto-backups (in Auto-Backup section)
    📦 View Imports — Old Duck.ai exports (in Manual Import section)

    ❓ Quick Guide

    📥 Download (Full Backup button)

    Saves conversations as .md files to your computer. Use this for permanent backups you want to keep.

    🔄 Auto-Backup

    Automatically saves conversations every few minutes inside the extension. No files downloaded until you export. Great for "set and forget" protection.

    📦 Import

    Bring back old Duck.ai backup files (.txt/.md) you saved before. Useful if you have old exports and want them in one place.

    💡 Which should I use?

    • New user? → Enable Auto-Backup, then do a Full Backup once a week
    • Have old backups? → Import them first, then use Full Backup
    • Want files on disk? → Use Full Backup or export from Auto-Backup
    ⚠️ Note: Old conversations that Duck.ai no longer has content for will be skipped during Full Backup if you've already imported them.
